ZeroS remote library

ZeroS built this library from three collections of IR codes and removed duplicate remotes. It stores every button as the timings the phone sends.

Flipper Devices IRDB
https://github.com/flipperdevices/IRDB, commit f7b15366
MIT licence, below.

IREXT
https://github.com/irext/database, irext_db_20260929
MIT licence, below.

Flipper-IRDB
https://github.com/Lucaslhm/Flipper-IRDB, commit d126fb1b
This library uses only the 124 files added after commit 2319685, the commit that put Flipper-IRDB under the CC0 1.0 licence (a public domain dedication). The rest of Flipper-IRDB has no licence, so ZeroS leaves it out. You can still download all of Flipper-IRDB in Settings.

The library has no air conditioner remotes.
