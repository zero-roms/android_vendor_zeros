# ZeroS changelog

ZeroS is a light Android 17 build based on LineageOS 24.0, for the Xiaomi
Redmi Note 8 (ginkgo). Versions before 1.0 are test builds.

## 0.5.1 (in progress)

- Google setup no longer stops on a blank screen at the Assistant step.
- Setup shows ZeroS's logo and colours, and its recovery page says ZeroS
  recovery. The page offering LineageOS statistics is gone (statistics stay
  off).
- Boot animation: the "oS" of ZeroS is red.
- Settings search finds "screen lock" and "password".
- About phone shows only the ZeroS version.
- Device diagnostics no longer shows "0% lifetime remaining" for storage on
  phones that do not report storage wear.
- Updater: ZeroS header, and links to this changelog and to the issue
  tracker.
- Bug reports: the Bug report tile, and Bug report in the power menu, open a
  ZeroS screen. Describe the problem there, then send the report to ZeroS,
  save it to Downloads or share it.
- Save to Downloads in the share menu copies any shared file into Downloads.
- ZeroS statistics replaces LineageOS statistics and reports to ZeroS. It
  stays off unless you switch it on.
- Settings > About phone > Legal information > ZeroS legal opens ZeroS's terms
  and privacy policy (LEGAL.md).

## 0.5.0 (24 October 2026)

- ZeroS boot animation and default wallpaper.
- Setup screens say ZeroS; LineageOS statistics start switched off.
- About phone shows the ZeroS version.
- Settings search finds Security and privacy.
- Device diagnostics shows the battery's real health instead of 0%.
- Digital Wellbeing's parental controls card opens the Play Store page of
  Google's System parental controls app when it is not installed.
- Bug report tile in quick settings.
- Updates arrive through the Updater (Settings > System > Updater).

## 0.4.0 (23 October 2026)

- Google build: Play Store and Play services (MindTheGapps, trimmed), Google
  backup and restore, Digital Wellbeing.
- Gboard as the keyboard, Cromite as the browser, NotallyX for notes.
- Signed with ZeroS's own release keys.

## 0.3.0 (22 October 2026)

- Fossify Gallery and File Manager.

## 0.2.0 (22 October 2026)

- About phone names ZeroS.
- Status bar clock, charging icon and privacy dot no longer clipped by the
  rounded screen corners.
- AudioFX and the FM radio app removed.

## 0.1.0 (18 October 2026)

- First ZeroS build.
